Role-Based Ecosystem Guide

Nexus secures data isolation and divides operational workflows through three explicit permission tiers, backed by corporate single sign-on (SSO).

Tier 1: Individual Employee

Core self-reporting interface for individual representatives.

1. View My Profile

Verify your personal demographic details, active reporting manager, and your full Skill Matrix Proficiencies as synced from the master AllEmployee directory.

2. Certify Monthly Allocation

Input monthly capacity splits across your assigned products in the BAU column (Non-BAU is currently locked at 0%). Management effort is now logged under the dedicated "Mgmt" Product/Sub-Product row in the BAU column.

Tier 2: Direct Manager

Team administration tool for resource planning and professional matrix tracking.

1. Manage Scope & Skills

Assign active operational products to direct reports, and manage their categorical skill proficiency ratings (SME, Intermediate, Beginner) directly via the Assign Skills panel.

2. Oversee & Proxy Allocations

Audit team capacity submissions in a centralized tri-state grid. Managers can execute Proxy Entries for team members who are OOO, and can Unlock/Reset mistaken entries instantly.

Tier 3: Platform Administrator

System security, database integrity governance, and control panel metrics.

Monitoring Center

Identify and flag missing allocations or uncertified allocations directly in the UI.

Drive Backups

Force system snapshots as Excel spreadsheets saved securely into Drive folders.

App State Toggle

Switch between Active, Locked, and Maintenance modes globally via Settings.

User Simulation

Log in as any employee securely to debug permission issues in real-time.

Smart Links Analytical Overlay

To guarantee optimal system speed, Nexus decouples transaction editing from data reporting. Editing and configuration happen on this lightweight Apps Script shell, while team analytics are served via external **Analytics Dashboards**.

Report Directory

Centralized links to all external Looker Studio reports.

Global Headcount

Visualize staff density by Cost Center, Role, and Region.

Cost of Delivery

Financial run-rate models splitting BAU vs Change effort.

CS Heatmap

Multi-axis matrices identifying single points of failure.

Platform RACI & Governance Matrix

Comprehensive governance matrix and role boundaries defining responsibilities across the 3-tier ecosystem.

Responsible Executes the task. Accountable Owns the final outcome. Consulted Provides input. Informed Receives visibility/output.

II. Tier 1: Employee (All CS) Boundaries

Responsible (R) / Accountable (A)

  • Profile Verification: Verify demographic data, active manager, and mapped products against Dayforce via the Home Profile. Report discrepancies to HR/Support.
  • Allocation Submission: Log total standard working days and weekend shifts.
  • FTE Compliance: Split monthly effort across assigned products ensuring the total equals exactly 100% (1.0 FTE) before certifying.

Informed (I) / Can Do

  • View active Skill Matrix Proficiencies assigned by managers.
  • Access the Analytics Hub to view the global Org Chart and Looker Report Directory.
  • Self-edit or update allocations only while the global submission window remains open.

Restricted (Cannot Do)

  • Add, remove, or modify personal products, sub-products, or skill ratings.
  • Manually change master HR profile data within the UI.
  • View Executive Analytics (Team skill levels, Cost of Delivery, Capacity Heatmaps).

III. Tier 2: Manager / Lead Boundaries

Responsible (R) / Accountable (A)

  • Team Governance: Ensure 100% of direct reports complete allocation certification by the monthly deadline.
  • Scope & Skills Mapping: Assign active products and rate L1-L5 skill proficiencies for team members via the Assign Skills/Products panels.
  • Auditing & Overrides: Review the centralized tri-state grid (Team Allocations) to track Green (Done) vs. Orange (Incomplete) statuses.
  • Fixing Gaps: Execute "Proxy Entries" for Out-Of-Office (OOO) reports and trigger "Reset/Unlock" to drop mistaken entries.
  • Strategic Analytics: Utilize the Analytics Hub to analyze team Cost of Delivery (Run vs. Change effort) and identify single points of failure via Skills/Allocation Heatmaps.

Informed (I) / Can Do

  • Receive CC notifications when Admins dispatch bulk reminder emails to uncertified team members.

Restricted (Cannot Do)

  • Dispatch automated bulk reminder emails directly to the team.
  • Edit global application lock states after the 1st-week submission window closes.
  • Modify the master employee HR roster.

IV. Tier 3: Platform Admin Boundaries

Responsible (R) / Accountable (A)

  • Compliance Monitoring: Scan global allocation certifications (Monitoring Center) to flag missing entries and verify strict FTE limits.
  • Enforcement: Select pending/uncertified users and dispatch system-wide bulk reminder emails.
  • System Integrity & Backups: Manually trigger ad-hoc system snapshots, save .xlsx archives to Drive, and lock-in historical month cycles.
  • Application State Control: Toggle the platform between Active, Locked, and Maintenance modes (System Settings).
  • Troubleshooting: Utilize Identity Simulation to securely log in as any user to debug permission access.
  • Dashboard Governance: Manage the visible Looker Studio links within the Report Hub Admin.
  • Platform Telemetry: Monitor Monthly Active Users (MAU), load speeds, and adoption metrics via the Nexus Adoption panel.

Restricted (Cannot Do)

  • Modify any transactional ledger allocations without keeping strict event logs.
